## 1️⃣ OpenAI's AI Autonomously Disproves an 80-Year Erdős Geometry Conjecture

- **What:** An internal OpenAI general-purpose reasoning model solved the planar unit distance problem — proving that n points can form n^(1+δ) unit-distance pairs, shattering the square-grid optimality assumption Paul Erdős made in 1946.
- **Why it matters:** This is the first time an AI has independently solved a prominent open problem at the frontier of a mathematical subfield, with the proof verified by multiple Fields medalists and Princeton combinatorialists.
- **Key number:** δ = 0.014 — the polynomial improvement exponent, later refined by Princeton mathematician Will Sawin after the AI's initial proof.

The breakthrough came from an unexpected direction: rather than attacking the geometry directly, the model drew on Golod-Shafarevich theory and infinite class field towers from algebraic number theory — a connection that surprised the discrete geometry community. OpenAI published companion remarks from Noga Alon (Princeton) and Thomas Bloom, both independently verifying the argument.

Fields medalist Tim Gowers called it "a milestone in AI mathematics." The model was not prompted to use number theory; it arrived there through its own reasoning chain. The result is undisputed, and the debate now centers on whether this constitutes genuine mathematical creativity or highly sophisticated pattern-matching operating across disciplinary boundaries.

## 2️⃣ Andrej Karpathy Joins Anthropic's Pre-Training Team

- **What:** Karpathy — OpenAI co-founder and former Tesla Autopilot lead — started at Anthropic on May 19 under pre-training team lead Nick Joseph, tasked with building a group that uses Claude to accelerate Claude's own pre-training research.
- **Why it matters:** Anthropic is betting that AI-assisted pre-training research is its structural competitive edge against OpenAI and Google's raw compute advantages.
- **Key number:** 3 — major AI organizations Karpathy has now worked at: OpenAI (co-founder, 2015), Tesla FSD (2017–2022), and now Anthropic.

Pre-training shapes a model's foundational capabilities through large-scale training runs. Karpathy will build a team that uses Claude itself to speed up that process — an AI-for-AI-research loop. It's an unusual bet: instead of matching rivals on GPU clusters, Anthropic is hiring the researcher who helped define modern LLM pre-training to redesign how it works from the inside.

Karpathy had most recently founded Eureka Labs in 2024, an AI-first education startup, before leaving to join Anthropic. His move signals that Anthropic — now projecting $10.9B in Q2 2026 revenue — has the resources and research ambition to attract talent that previously defined the field elsewhere.

## 3️⃣ Anthropic Ships MCP Tunnels and Self-Hosted Sandboxes for Enterprise Agents

- **What:** Anthropic announced self-hosted sandboxes (public beta) and MCP tunnels (research preview) at Code with Claude London on May 19, letting enterprises run Claude's tool-execution layer on their own infrastructure while connecting to private MCP servers without exposing them to the public internet.
- **Why it matters:** Data sovereignty concerns have been the primary blocker for enterprise Claude agent adoption; this removes the need to open inbound firewall rules or route sensitive files through Anthropic's infrastructure.
- **Key number:** 4 managed compute providers supported from day one: Cloudflare, Daytona, Modal, and Vercel.

With self-hosted sandboxes, the agent loop — orchestration, context management, error recovery — stays on Anthropic's servers, while file I/O, code execution, and compute-intensive builds happen entirely inside the customer's perimeter. Existing network policies, audit logs, and security tooling remain in place; resource sizing and runtime images are customer-controlled.

MCP tunnels work through a lightweight gateway deployed inside the customer's network that establishes a single outbound encrypted connection to Anthropic's routing infrastructure. No inbound firewall rules are required and no public DNS entries are needed. Private MCP servers remain unreachable from the public internet. Together, the two features give regulated-industry security teams the control they need to approve Claude agents without creating new attack surface.
