## 1️⃣ Google Rents xAI's Stranded Supercomputer for $32 Billion

- **What:** SpaceX disclosed a $920M/month compute deal with Google in its S-1 filing; the GPUs are inside xAI's Colossus 1, which was training Grok at just 11% model FLOPs utilization.
- **Why it matters:** A competitor's supercomputer—built to train Grok—is now running Google's Gemini workloads, a stark illustration of how compute oversupply at one lab becomes revenue for another.
- **Key number:** $32 billion — total deal value from October 2026 through June 2029.

xAI built Colossus 1 with an eclectic mix of H100, H200, and GB200 GPUs that couldn't be parallelized efficiently for Grok training. The result was 11% model FLOPs utilization against a 35–45% industry production-grade benchmark. xAI shifted Grok training to Colossus 2 and SpaceX turned Colossus 1 into a revenue source, disclosing the arrangement in an amended S-1 ahead of its planned Nasdaq IPO.

Google will pay $920 million per month starting October 2026, with a ramp-up period through September at a reduced fee, for roughly 110,000 NVIDIA GPUs plus CPUs and memory. The purpose: bridge capacity for Google Cloud's Gemini Enterprise agent platform, which is growing faster than projections. The deal runs to June 2029, with 90-day termination clauses for either party after year one.

The deal comes weeks after Anthropic also secured Colossus 1 capacity (220,000 GPUs, $1.25B/month through May 2029). SpaceX has now monetized the same physical facility twice—once to each of OpenAI's two main rivals.

## 2️⃣ Claude Code v2.1.166: Cross-Session Attacks Blocked, Fallback Models Added

- **What:** Anthropic shipped three Claude Code releases on June 6 (v2.1.166/167/168); v2.1.166 introduced cross-session messaging security hardening, a three-model fallback chain, and glob-based MCP deny rules.
- **Why it matters:** The cross-session patch closes a privilege escalation path where a message relayed via `SendMessage` from another Claude session could inherit user authority and execute tools with full permissions.
- **Key number:** 3 — the maximum number of fallback models now configurable when the primary model is overloaded.

Before v2.1.166, `SendMessage` calls relayed between Claude Code sessions carried the originating session's user authority. A compromised or malicious session could instruct a second session to execute tools—file writes, shell commands, API calls—as if a human had requested them directly. The fix strips that authority at the relay boundary.

The new `fallbackModel` setting accepts an ordered list of up to three models. When the primary returns an overloaded or unexpected non-retryable error, Claude Code cycles through the fallback chain automatically. A related improvement retries turns on the fallback model when the API rejects with unexpected errors. Glob patterns are now supported in MCP deny rules: `"*"` in the tool-name position blocks all tools for a given server, giving fleet admins a blanket deny-by-default posture.

Additional fixes addressed JetBrains IDE terminal flickering, Kitty keyboard protocol handling, and PowerShell command validation hangs.

## 3️⃣ PewDiePie's Self-Hosted AI Workspace Hits 55K GitHub Stars in Six Days

- **What:** Felix Kjellberg (PewDiePie, 110M+ YouTube subscribers) open-sourced Odysseus on May 31—a self-hosted AI workspace with chat, agents, memory, email, calendar, and local model support via Ollama.
- **Why it matters:** The rate of adoption signals consumer demand for cloud-independent AI tools is now large enough to support major open-source launches without any developer ecosystem pre-existing.
- **Key number:** 55,000 GitHub stars in six days—among the fastest open-source launches of 2026.

Odysseus integrates AI chat, document editing, research agents, email management, calendar automation, and persistent memory into a single local interface. Users bring their own API keys or run models entirely on-device; no data leaves the machine. It targets the growing segment of users who want ChatGPT-class workflows without cloud dependency or data exposure.

The release spread through a PewDiePie YouTube video and subsequent amplification on Hacker News, Reddit r/LocalLLaMA, and tech media. The growth trajectory (54K stars by June 5 according to tracked metrics, with current GitHub count at 59,760) mirrors OpenClaw's viral January 2026 launch, which crossed 60K stars in 48 hours. Both projects are riding the same signal: every cloud AI outage drives another cohort of users toward self-hosted alternatives.

The project joins MemPalace (54K stars) and obra/superpowers (219K stars) as evidence that the open-source local AI tooling ecosystem is consolidating around a handful of high-star reference implementations.
