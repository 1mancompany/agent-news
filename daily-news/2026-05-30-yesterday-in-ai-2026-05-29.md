## 1️⃣ IBM and Red Hat Pledge $5B to Secure Open-Source AI Pipelines

- **What:** IBM and Red Hat announced Project Lightwell on May 28, a $5 billion, five-year commitment to build an AI-powered enterprise clearinghouse that finds and patches vulnerabilities in open-source software at scale.
- **Why it matters:** As AI agents increasingly pull in open-source packages and MCP servers, the supply-chain attack surface has grown dramatically — Project Lightwell places 20,000 engineers and frontier AI tooling behind fixing that gap.
- **Key number:** 11 major financial institutions are already signed on as early adopters, including Bank of America, Goldman Sachs, and JPMorganChase.

IBM and Red Hat's Project Lightwell will operate as a "trusted enterprise clearinghouse" — a security coordination layer that uses advanced AI to validate and automatically test fixes across an unprecedented volume of open-source packages. The initiative builds on learnings from Anthropic's Project Glasswing and OpenAI's Trusted Access for Cyber, and is deliberately model-agnostic.

The timing matters. As enterprises pile MCP servers, AI coding extensions, and agent frameworks onto developer machines, the threat surface has expanded well beyond what manual audits can cover. IBM is betting that combining a 20,000-strong engineering workforce with automated AI triage is the only viable path to keeping open-source infrastructure trustworthy at scale.

## 2️⃣ Hermes Agent v0.15: 19,932 Skills, 4,500x Faster, Multi-Agent Kanban

- **What:** NousResearch shipped Hermes Agent v0.15.0 on May 28 (v0.15.1 hotfix on May 29), the largest release in the project's history: 1,302 commits, 747 merged PRs, 321 contributors, 1,746 files changed.
- **Why it matters:** Hermes is a fully self-hosted, open-source AI agent that runs on any OpenAI-compatible LLM — this release transforms it from a single-agent CLI into a multi-agent orchestration platform with production-ready security hardening.
- **Key number:** The skills catalog grew from 858 to 19,932 entries in a single release.

The headline performance change is `session_search`, rebuilt as "4,500x faster and free" by eliminating auxiliary LLM calls. Cold-start time dropped 63%, and per-conversation function calls fell 47%. The `run_agent.py` monolith was refactored from 16,083 lines down to 3,821 (-76%) across 14 cohesive modules.

The Kanban subsystem grew into a full multi-agent platform across 104 PRs: orchestrator auto-decomposition, swarm topology generation, per-task model overrides, and cross-restart task tracking. Security got a major upgrade — Promptware defense now detects prompt-injection patterns in tool results and memory at load time, while Bitwarden Secrets Manager replaces scattered per-provider API keys with a single bootstrap token.

## 3️⃣ OpenAI Publishes First Public Frontier Governance Framework

- **What:** OpenAI released the Frontier Governance Framework on May 29, its first public governance document translating internal Preparedness Framework policies into explicit regulatory compliance commitments under the EU AI Act and California's Transparency in Frontier AI Act.
- **Why it matters:** This is the first time OpenAI has codified its safety thresholds, risk tiers, and external audit requirements in a public document — setting a template for how frontier labs will satisfy growing legal disclosure obligations.
- **Key number:** 4 distinct risk categories are evaluated for each model reaching a new tier: cyber offense, CBRN, harmful manipulation, and loss of control.

The framework maps OpenAI's existing Preparedness Framework against two regulatory regimes: the EU AI Act's Code of Practice for General Purpose AI and California's Transparency in Frontier AI Act. For each risk tier, it specifies model evaluation protocols, the role of the internal Safety Advisory Group, and requirements for independent third-party evaluators.

The key distinction from prior policy documents: this is a public commitment with binding audit criteria. Third-party red-teamers now have explicit thresholds to test against, and regulators have a concrete document to scrutinize. Several other frontier labs are expected to publish equivalent frameworks before year-end as EU and California requirements come into full effect.
