## 1️⃣ Anthropic Played Partner Then Played Competitor — 13 Times

- **What:** The Information reports Anthropic launched 13 vertical AI products since February 2025, consistently without warning the business partners it was undercutting.
- **Why it matters:** Companies building on Claude are now discovering they helped fund a direct competitor; Figma, invited to co-announce Claude Design in April, has seen its stock drop 49% since January.
- **Key number:** 13 vertical products shipped in 16 months with no consistent pre-warning to affected partners.

The Information's story centers on a pattern, not a single incident. Anthropic's Claude Design (launched April 2026) targets the same UI/prototyping market as Figma and Canva. Anthropic reportedly asked both firms to participate in its launch announcement — framing them as partners — while keeping the competitive nature of the product quiet. When Claude Design shipped, design software stocks cratered.

The behavior extends beyond design. Anthropic has built into coding (Claude Code), business intelligence, healthcare, and legal verticals, each time competing with ISVs that had built their offerings on top of Claude's API. For enterprise customers paying for both Claude API access and purpose-built software built on it, the conflict of interest is now impossible to ignore.

Anthropic hasn't confirmed or denied the 13-product count. The broader concern for the AI ecosystem is structural: if the model provider becomes the app provider without warning, the risk premium on building anything Claude-dependent just increased significantly.

## 2️⃣ Moonshot Drops a 1-Trillion-Parameter Coding Model — For Free

- **What:** Moonshot AI released Kimi K2.7-Code on Hugging Face, a 1-trillion-parameter MoE coding model under a Modified MIT license.
- **Why it matters:** It beats its predecessor by 21.8% on Kimi Code Bench v2 while consuming 30% fewer reasoning tokens — better results at lower cost, fully open-weight.
- **Key number:** +21.8% on Kimi Code Bench v2 over K2.6, with a 256K-token context window.

Kimi K2.7-Code runs on a Mixture-of-Experts architecture: 1 trillion parameters total, 32 billion active per forward pass across 384 experts. That design keeps inference cost tractable while scaling capacity. The 256K-token context window handles most real-world repositories in a single pass.

The 30% reasoning-token reduction is the practical headline for builders. K2.6 was already competitive on coding tasks; K2.7-Code cuts the thinking budget without trading away quality, meaning lower API costs for the same output on agentic coding workloads. The model is now on Hugging Face under a Modified MIT license — commercially usable with attribution.

This is the fifth major Kimi coding release in under a year. Note that the 21.8% figure comes from Moonshot's own Kimi Code Bench v2; independent results on SWE-bench Verified or LiveCodeBench have not yet been published.

## 3️⃣ OpenAI Retires GPT-5.2 — Millions Auto-Migrated to GPT-5.5

- **What:** OpenAI deprecated GPT-5.2 Instant, Thinking, and Pro in ChatGPT effective June 12, with existing conversations silently migrating to the corresponding GPT-5.5 variant.
- **Why it matters:** Developers relying on the API face a hard deadline — new requests return errors after June 30, and the endpoints disappear December 31.
- **Key number:** June 30, 2026 — the date new API calls to gpt-5.2-* start failing.

The retirement was telegraphed. OpenAI posted a GitHub Changelog notice on May 1, giving developers six weeks to migrate. For ChatGPT users the transition is invisible; for API developers, the migration is a one-line model-name change. The path from gpt-5.2-chat-latest points to gpt-5.5.

GPT-5.3-Codex follows the same sunset schedule. OpenAI's broader signal is that the 5.x minor-version accumulation is consolidating around GPT-5.5 as the stable production tier. GPT-5.6 (internally codenamed Kindle-Alpha, reportedly targeting a 1.5M-token context window) is in testing and expected to eventually replace 5.5 once it clears safety evaluation.

For any team still sending requests to GPT-5.2: switch to gpt-5.5 before June 30 — the migration is low-friction and the capabilities gap is real.
