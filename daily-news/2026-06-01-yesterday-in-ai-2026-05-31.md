## 1️⃣ Opus 4.8: A 27-Point Math Leap and 1,000-Agent Workflows

- **What:** Anthropic released Claude Opus 4.8 on May 28, just 41 days after Opus 4.7, delivering the largest single-cycle math gain in the model line's history.
- **Why it matters:** A model that closes nearly the entire gap to perfect on USAMO—while dropping 35% fewer output tokens—directly cuts inference cost on heavy workloads.
- **Key number:** USAMO 2026 score jumped from 69.3% → 96.7% (+27.4 points).

Opus 4.8 scores 88.6% on SWE-bench Verified (up from 87.6%), 69.2% on SWE-bench Pro (up from 64.3%), and 68.1% on GraphWalks long-context F1 at one million tokens (up from 40.3%). Anthropic held pricing flat: $5/$25 per million tokens standard, $10/$50 for Fast mode at 2.5× speed—three times cheaper than Fast mode was on Opus 4.7.

The headlining Claude Code addition is Dynamic Workflows (research preview), which lets the model write an orchestration script, spawn up to 1,000 subagents in parallel, verify their outputs, and surface a final report. A companion `/effort xhigh` flag enables maximum reasoning effort. Both require Enterprise, Team, or Max plans.

## 2️⃣ Claude Code Ships Free Security Plugin — 25 Patterns, 3-Layer Review

- **What:** Anthropic released the security-guidance plugin for Claude Code on May 27, scanning every edit for 25 high-risk vulnerability classes in real time.
- **Why it matters:** Catching injection flaws, hardcoded secrets, and insecure deserialization before a commit removes a whole class of late-stage security debt.
- **Key number:** 30–40% drop in security-related PR comments in internal rollout.

The plugin runs three passes: a fast regex pattern check on each file edit, a model review after every turn, and a deeper agentic scan on commit or push. The 25 patterns cover SQL injection, command injection, XSS, insecure deserialization, hardcoded API keys, and improper input validation. It requires Claude Code v2.1.144 or later, is free on all plans, and installs from the plugin marketplace with `/plugins`.

## 3️⃣ Gemini Spark Goes Live in the US at $100/Month

- **What:** Google opened Gemini Spark beta to US Google AI Ultra subscribers on May 29, making it a 24/7 personal AI agent that runs in the cloud without a browser tab.
- **Why it matters:** An agent that receives tasks by email, browses Chrome, and works overnight on Workspace data represents a new asynchronous AI delivery model.
- **Key number:** Google AI Ultra dropped from $250 to $99.99/month to anchor Spark adoption.

Spark runs on Gemini 3.5 using Google's Antigravity harness and integrates natively with Gmail, Docs, Slides, and Calendar. Third-party integrations at launch include Canva, OpenTable, and Instacart. Tasks can be queued by emailing a dedicated address; Spark plans and executes without further prompting. The rollout is US only, English only—no international timeline has been announced.

## 4️⃣ OpenClaw v2026.5.28: Claude Opus 4.8 Support and Copilot Runtime

- **What:** OpenClaw shipped its first stable release of May on May 30 UTC, adding Claude Opus 4.8 as a supported model and integrating GitHub Copilot's agent runtime.
- **Why it matters:** OpenClaw (350K+ GitHub stars) routes AI across 20+ messaging channels; adding Opus 4.8 and Copilot runtime extends it into enterprise developer toolchains.
- **Key number:** Three follow-up beta releases dropped on May 31 alone, shipping Skill Workshop and Workboard multi-agent coordination.

The stable release tightens agent runtime recovery: interrupted tool calls, stale session bindings, compaction handoffs, and media delivery retries now recover cleanly. The new Skill Workshop is a proposal management system for building and sharing agent skills; Workboard adds delegation tools for multi-agent task coordination. Betas on May 31 extended iOS push relay support and improved channel stability across Telegram, Discord, Teams, and WhatsApp.
