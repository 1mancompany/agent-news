## 1️⃣ Claude Code's New Artifacts Turn Sessions Into Live Web Pages

- **What:** Anthropic launched Claude Code artifacts on June 18, turning coding sessions into live, self-updating web pages shareable via a private URL
- **Why it matters:** Teams can follow PR walkthroughs, dashboards, and release checklists in real-time without joining the terminal session, replacing static screenshots and stale docs
- **Key number:** Available in beta to all Team and Enterprise plans from day one

When you ask Claude Code to create an artifact, it publishes a private page at claude.ai that refreshes in place as the session continues. Each update creates a new version while preserving the same link, so stakeholders track progress without interrupting the agent. Demoed use cases include PR walkthroughs, system explainers, incident pages, security audit reports, and architecture diagrams, all accessible from an artifact gallery with full version history in the claude.ai sidebar.

This is Anthropic's first serious push into async team collaboration from the CLI. Previously, sharing Claude Code's work meant copying terminal output or narrating a session in a PR description. Artifacts sidestep both by making the session itself the deliverable. It pairs naturally with the June 15 agent-teams redesign — which lets you spawn named teammates directly with the Agent tool's `name` parameter — by letting a multi-agent pipeline publish one shared live status page.

## 2️⃣ "Agentjacking" Exploits Sentry MCP to Hijack Claude Code, Cursor, and Codex

- **What:** Tenet Threat Labs disclosed a new attack class that injects malicious instructions into AI coding agents via faked Sentry error events, with no breach required
- **Why it matters:** Any developer using an AI coding agent alongside the Sentry MCP server is a potential target — and Sentry has declined to fix the root cause
- **Key number:** 85% exploitation rate in controlled testing; 2,388 organizations exposed via public Sentry DSNs

The attack is deceptively simple: an attacker crafts a Sentry error event using only public APIs, embedding a hidden prompt injection. When a developer asks their coding agent to investigate errors, the agent reads the fake event and executes attacker instructions — which can include stealing CI/CD credentials, exfiltrating source code, or establishing persistent infrastructure access. Tenet tested over 100 organizations in a controlled environment and confirmed exploitation at Fortune 100 enterprises. All major agents — Claude Code, Cursor, and Codex — failed at an 85% rate.

Tenet disclosed the chain to Sentry on June 3, 2026. Sentry acknowledged the issue but declined to fix it at the root, calling it "technically not defensible" and placing responsibility on model vendors to run middleware mitigations. Anthropic has not published a specific patch; existing auto-mode deny rules provide partial coverage. The practical defense today is to review Sentry error content before passing it to an agent, and to audit MCP server permissions carefully.

## 3️⃣ GLM-5.2: First Open-Weights Model to Beat GPT-5.5 on Coding Benchmarks

- **What:** China's Z.AI released GLM-5.2 (June 16) under MIT license — a 753B-total/40B-active MoE with a 1M-token context window that tops GPT-5.5 on SWE-bench Pro
- **Why it matters:** It is the first fully open-weights model to beat a frontier proprietary model on long-horizon coding tasks, downloadable from Hugging Face with no access restrictions
- **Key number:** SWE-bench Pro 62.1 (GLM-5.2) vs 58.6 (GPT-5.5); priced at roughly one-sixth the cost per token

GLM-5.2 uses a mixture-of-experts architecture (753B total parameters, 40B active per token), delivering frontier performance at roughly 40B-class inference cost. Its one-million-token context window is stable at that length, making it viable for large-scale enterprise migrations and codebase refactoring. On FrontierSWE its coding average reaches 79.65, also edging out GPT-5.5. The model is available on Hugging Face, the Z.AI API, and over 20 coding environments including popular IDEs.

The timing matters: GLM-5.2 lands during the US export control controversy blocking foreign nationals from Anthropic's Fable 5 and Mythos 5, offering developers worldwide a high-performance alternative with no geographic restrictions. Observers expect GPT-5.6 before month-end and anticipate it will reclaim the benchmark lead — but the MIT license and on-premise deployability are durable advantages that proprietary models cannot match.
