## 1️⃣ Claude Fable 5: Mythos-Class AI Goes Public at $10/$50 per MTok

- **What:** Anthropic released Claude Fable 5 on June 9, making its highest-capability model tier generally available for the first time, alongside a limited-access Claude Mythos 5 for vetted cyber defenders and infrastructure providers.
- **Why it matters:** At 80.3% on SWE-Bench Pro — versus 69.2% for Opus 4.8, 58.6% for GPT-5.5, and 54.2% for Gemini 3.1 Pro — Fable 5 is now the clear leader for agentic coding, priced at $10/$50 per million input/output tokens with a 90% caching discount.
- **Key number:** 80.3% SWE-Bench Pro — a 21.7-point lead over the nearest rival.

Claude Fable 5 is the GA release of Anthropic's Mythos model tier, previously gated to a small early-access cohort. The model ships with a novel set of safety classifiers that silently reroute queries touching cybersecurity, biology, chemistry, or model distillation to a less capable fallback — the first production model where a user's request may be answered by a different model than the one they selected.

On long-horizon agentic work, Anthropic benchmarked the model using the deck-building game Slay the Spire with persistent file-based memory. Fable 5 improved three times faster than Opus 4.8 across game sessions and reached the final act three times as often. The model launched simultaneously on the Claude API, AWS Bedrock, and as a GA option inside GitHub Copilot.

## 2️⃣ Claude Code 2.1.169: Safe Mode, /cd, and Hardened Enterprise Controls

- **What:** Anthropic shipped Claude Code version 2.1.169, adding `--safe-mode` to disable all customizations for troubleshooting, a `/cd` command to change directories mid-session without cache breaks, and `disableBundledSkills` for enterprise environments.
- **Why it matters:** Safe mode addresses the most common support request — "is this a Claude Code bug or my hook?" — without requiring a fresh session; the enterprise MCP policy fixes unblock teams whose `allowedMcpServers` rules were silently not enforcing on reconnect.
- **Key number:** 20+ bug fixes shipped alongside three new developer-facing features.

The `--safe-mode` flag (also set via `CLAUDE_CODE_SAFE_MODE`) disables CLAUDE.md, plugins, skills, hooks, and MCP servers in a single command. The new `/cd` command moves a session to a new working directory without breaking the prompt cache mid-session. The `disableBundledSkills` setting hides built-in slash commands from the model, useful for teams that want to expose only approved workflows.

The self-hosted runner gained a `post-session` lifecycle hook that fires after the session ends and before the workspace is deleted — enabling uncommitted-work snapshots or log exports. A macOS-specific 30–50ms UI stall at the start of each turn (triggered for users logged in with claude.ai OAuth) was also eliminated. Version 2.1.170, released the same day, adds Fable 5 model access and fixes a transcript-saving regression in VS Code integrated terminals.

## 3️⃣ Open-Notebook Clears 28K Stars: Self-Hosted NotebookLM Gains Momentum

- **What:** Open-Notebook (lfnovo/open-notebook), an open-source self-hostable alternative to Google's NotebookLM, crossed 28,152 GitHub stars after gaining 3,891 in the past seven days.
- **Why it matters:** As Google moves to shutter the open-source Gemini CLI and NotebookLM keeps user documents in Google's cloud, demand for transparent, locally-run research tools is accelerating among privacy-conscious developers.
- **Key number:** 3,891 stars in seven days — from ~24K to 28K.

Open-Notebook supports 18+ AI providers — including Claude, OpenAI, Gemini, Ollama, and LM Studio — so users are not locked into a single vendor. Unlike NotebookLM, it processes PDFs, videos, audio files, and web pages on the user's own machine. The project generates research podcasts with up to four speakers, includes full vector search, and exposes a REST API for integration with other tools.

The recent star surge followed the team shipping v1.9.0 in early June, which picked up 783 stars in a single day. The project has been gaining steady traction as an answer to the closed-source turn many AI productivity tools are taking, and stands out as one of the few NotebookLM alternatives that meaningfully exceeds the original in feature count.
