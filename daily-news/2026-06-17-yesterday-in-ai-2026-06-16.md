## 1⃣ Claude's 10th Outage in 12 Days: Infrastructure Reckoning

- **What:** Claude suffered its tenth service disruption since June 5, with Opus 4.8 and Haiku 4.5 errors persisting despite a 2:00 PM ET fix attempt — users began reporting seeing fragments of other users' sessions, prompting an Anthropic data-leak investigation.
- **Why it matters:** Ten outages in 12 days signals a structural failure, not bad luck. Claude is now critical infrastructure for thousands of businesses; each disruption cascades across every product that depends on it.
- **Key number:** $9B → $30B+ — Anthropic's annualized revenue growth from end-2025 to April 2026, out-pacing infrastructure scaling.

Anthropic has acknowledged that "demand for Claude has grown at an unprecedented rate, and our infrastructure has been stretched." The June 16 disruption affected Opus 4.8 and Haiku 4.5 (Claude Console and Claude for Government remained up). More worrying: users reported seeing fragments of other users' sessions — potential session-boundary failures during the degraded window. Anthropic stated it was "investigating" but had seen no confirmed evidence of data crossing accounts. The company has published no post-incident root cause analyses for any of its ten June outages, a transparency gap enterprise buyers are starting to flag publicly.

## 2⃣ LiteLLM CVSS 9.9: Four Bugs That Hand Over Every Provider Key

- **What:** Obsidian Security disclosed a four-CVE chain in LiteLLM proxy letting any logged-in user escalate to full admin and run arbitrary code, exposing all configured API keys — Anthropic, OpenAI, Gemini, Bedrock, Azure.
- **Why it matters:** LiteLLM is the most widely deployed self-hosted AI gateway; this is a full-stack key-theft attack on any unpatched instance, including those routing Claude Code or MCP traffic.
- **Key number:** CVE-2026-42271 entered CISA's Known Exploited Vulnerabilities catalog within days of disclosure — active exploitation confirmed in the wild.

The chain needs only a default low-privilege account. CVE-2026-47101: mint an admin-scoped key via unguarded key-management endpoints. CVE-2026-47102: promote yourself to `proxy_admin` through an unprotected `user_role` field. CVE-2026-40217: escape to code execution via the Custom Code Guardrail's unfiltered `exec()`. A fourth standalone RCE (CVE-2026-42271) was separately weaponized and added to the CISA KEV list. The full blast radius: master key, credential-decryption salt, database URL, and every downstream provider key the proxy holds. Patch to v1.83.14-stable immediately; treat all stored keys as compromised pending audit.

- **Why it matters:** Hermes has become the de-facto open-source general-purpose agent, with a 90,000-skill ecosystem and a native desktop app drawing users who want a self-hosted alternative to cloud-locked coding agents.

The Skills Hub now lists 90,881 skills across 12 registries — a full app-store model for agent extensibility. The repo's topics include `openclaw`, `claude-code`, and `codex`, signaling design intent to front any major AI coding environment. At roughly 1,000 new stars per day, Hermes Agent is on pace to cross 200K before the end of June.
