## 1️⃣ Microsoft Build 2026: 7 In-House Models, GPT-4 Turbo Out by August

- **What:** Microsoft unveiled 7 new MAI models at Build 2026 on June 2, led by MAI-Thinking-1 (35B active parameters, no OpenAI training data) and MAI-Code-1-Flash (5B, rolling out to all Copilot tiers today); Project Polaris will replace GPT-4 Turbo as GitHub Copilot's default engine by August 2026.
- **Why it matters:** This ends GitHub Copilot's OpenAI dependency — the world's most-used AI coding assistant will run entirely on Microsoft's own stack within two months.
- **Key number:** MAI-Code-1-Flash scores 51.2% on SWE-Bench Pro vs 35.2% for Claude Haiku 4.5, a 16-point gap, while using 60% fewer tokens on complex tasks.

MAI-Thinking-1 is a sparse Mixture-of-Experts reasoning model with 35B active parameters and a 256K context window, trained from scratch on commercially licensed data with no distillation from third-party models. Microsoft reports 97.0% on AIME 2025 and a match to Claude Opus 4.6 on SWE-Bench Pro; in blind side-by-side evaluations by independent rater Surge, it outperformed Claude Sonnet 4.6.

MAI-Code-1-Flash is available today across Free, Pro, Pro+, and Max GitHub Copilot plans. Adaptive solution length control lets it stay concise for simple requests and expand its reasoning budget for harder problems. Project Polaris completes its rollout in August, ending Copilot's OpenAI model dependency entirely.

Also shipped at Build: multi-agent VS Code with a planner-and-specialist subagent architecture, Azure Agent Mesh for cross-cloud agent coordination, Windows Agent Framework 1.0, and Copilot Workspace general availability for GitHub Enterprise.

## 2️⃣ Glasswing Grows: Claude Mythos Reaches NATO, 150 New Orgs, 23K Vulns

- **What:** Anthropic expanded Project Glasswing on June 2 to 150 additional organizations across 15+ countries — including NATO, EU cybersecurity agency ENISA, Okta, Samsung, and SK Hynix — granting access to Claude Mythos Preview, an unreleased model built for superhuman vulnerability discovery.
- **Why it matters:** Giving a frontier AI model sanctioned access to military and pan-European regulatory infrastructure is unprecedented; at scale, it can harden shared critical systems faster than any human red-team program.
- **Key number:** Claude Mythos scanned 1,000+ open-source projects and flagged 23,019 potential vulnerabilities; 6,202 rated high or critical.

Project Glasswing launched in April 2026 with 50 initial partners including U.S. government agencies. The June 2 expansion fills gaps in coverage: power grids, water systems, healthcare networks, telecommunications, and chip hardware were underrepresented in the first cohort. Anthropic describes Claude Mythos Preview as capable of surpassing all but the most skilled humans at finding and exploiting software weaknesses.

Participating organizations receive Mythos access to scan their own codebases and patch vulnerabilities on their own timelines before any public disclosure. Anthropic has not announced a general-availability date for Mythos, and the model remains restricted to vetted Glasswing partners.

## 3️⃣ MiniMax M3: Open-Weight Model Claims Frontier Coding in 1M Context

- **What:** MiniMax launched M3 on June 1, the first open-weight model claiming frontier-level coding performance, with a 1M-token context window, native multimodality, and an MSA architecture that cuts per-token compute to one-twentieth of the previous generation at 1M context; weights arrive on Hugging Face around June 11.
- **Why it matters:** If independent benchmarks confirm the scores, M3 becomes the strongest freely downloadable coding model — critical for enterprises unwilling to route proprietary code through closed APIs.
- **Key number:** 59.0% on SWE-Bench Pro (self-reported), 9x faster prefill and 15x faster decoding vs MiniMax M2 via Multi-Sparse-Attention architecture.

M3 is live now via the MiniMax API and MiniMax Code platform. Its Multi-Sparse-Attention (MSA) architecture replaces dense attention with sparse blocks, slashing inference cost dramatically at long context. Pricing for the open-weight license is not yet set; MiniMax's prior M2.7 shipped under a modified MIT that restricted commercial use, and M3 is expected to follow a similar model.

Benchmark caveats are significant: several SWE-Bench Pro runs used MiniMax's own infrastructure and custom agent scaffolding, and independent replication is pending the Hugging Face weight release. The repo to watch is huggingface.co/MiniMaxAI. If scores hold, M3 would represent the clearest evidence yet that open weights can match closed-source frontier models on real-world software engineering tasks.
