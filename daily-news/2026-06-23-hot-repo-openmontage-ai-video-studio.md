## What It Does

OpenMontage is an open-source, agent-first video production system built on 12 specialized pipelines, 52 tools, and 500+ agent skills. Unlike AI video generators that animate static images and call it a day, OpenMontage executes a complete production workflow — research, scripting, asset sourcing, voiceover, editing, and rendering — through any AI coding assistant including Claude Code, Cursor, GitHub Copilot, Windsurf, and Codex. There is no separate code orchestrator; the AI coding assistant itself directs every stage.

## Quick Start

```bash

```

Open the project in Claude Code or Cursor and type: *"Make a 60-second animated explainer about how neural networks learn"* — the agent handles everything from research to final render.
