## 1️⃣ Claude Code v2.1.287 Ships Mods — TypeScript Now Controls the Agent

- **What:** Anthropic shipped mods in Claude Code v2.1.287: small TypeScript functions installable via `/plugin` that intercept and rewrite every layer of the agent
- **Why it matters:** Developers can now enforce security policies, swap UI elements, and gate permissions without forking internals — the agent is fully extensible from the outside
- **Key number:** 4 built-in mods (diff, agents-md, sec-default, telemetry) ship with public source in `anthropics/claude-code` as ready templates

Claude Code v2.1.287 arrived on October 1 with "mods" — a new extensibility layer between user input and the model. A mod can rewrite a prompt before it reaches the model, intercept and block tool calls, approve or deny permission requests, and redact secrets from tool output. Mods can also redraw parts of the Claude Code UI and add buttons and inputs — and multiple mods can compose, so one mod can react to another's events.

Mods install via `/plugin` in the CLI or desktop app; a developer can write one with a few lines of TypeScript or ask Claude to generate it. Four Anthropic-authored mods — diff, agents-md, sec-default, and telemetry — have open-sourced code in the main claude-code repo as starter templates.

Unlike earlier plugin systems that appended new tools or commands, mods can intercept the agent's core decision loop, making them well-suited for enterprise security rules, personal workflow patches, and shareable plugin libraries.

## 2️⃣ Cloudflare Launches Clef — An Open-Source Challenge to TypeSafe's Jev

- **What:** Cloudflare released Clef and Clef-flash, open-source decision models on Workers AI and free on Hugging Face under Apache 2.0
- **Why it matters:** "System One" decision models are becoming agent infrastructure; Cloudflare's entry gives every developer a free, edge-native alternative to Jev
- **Key number:** Jev costs $0.042/M input tokens and claims 193x the speed of Claude Sonnet 5 — Cloudflare says Clef beats it on both latency and benchmark scores

TypeSafe's Jev launched in September as the first dedicated decision model for AI agents — structured choices only (routing, guardrails, classification, confidence scores), no prose, at 193x the speed and ~444x the cost savings of generalist models. Cloudflare answered October 1 with Clef and the faster Clef-flash.

Both models target the same pipeline slot: answering agent micro-questions like "which tool?", "is this safe?", "escalate?". Running on Workers AI, they co-locate with agent workloads at the edge. Apache 2.0 means they can be fine-tuned and self-hosted without restriction.

Cloudflare's entry is the first real competition Jev has faced and signals the System One decision-model category is maturing fast enough to attract platform players.

## 3️⃣ OpenRig: 781 Stars in One Day for Running Claude Code + Codex as One Team

- **What:** OpenRig (mvschwarz/openrig) is an open-source harness that runs Claude Code and OpenAI Codex as a coordinated agent team, orchestrated via a YAML RigSpec and tmux
- **Why it matters:** Multi-agent coding topologies have been hand-rolled by developers; OpenRig packages the pattern with proven starter configs including adversarial code review
- **Key number:** 1,578 total stars with 781 gained in a single day after the Show HN post

OpenRig defines agent teams in YAML — seats (one per agent), pods (groups), and edges (message paths). `rig up` starts all agents in tmux. The four included starter rigs are first-project, product-team, adversarial-review, and research-team.

Adversarial-review is the standout: one Claude Code agent writes code while a Codex agent independently reviews and pushes back, surfacing disagreements before a commit lands. Plain terminal nodes are also supported, so any shell command can join the message graph alongside AI agents.

Version 0.5.17, released September 27, added Bun support alongside npm. The 781-star single-day surge signals pent-up demand for multi-provider agent orchestration with no vendor lock-in.
