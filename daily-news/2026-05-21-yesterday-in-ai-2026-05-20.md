## 1️⃣ Cursor Composer 2.5: Frontier Benchmark at a Fraction of the Cost

- **What:** Cursor released Composer 2.5 on May 18—its in-house agentic coding model scoring 79.8% on SWE-bench Multilingual, nearly matching Claude Opus 4.7 (80.5%), at $0.50/$2.50 per million input/output tokens.
- **Why it matters:** Cursor previously depended on Anthropic and OpenAI models it also competed against; Composer 2.5 breaks that dependency while cutting per-token costs roughly 10–30x versus comparable frontier models.
- **Key number:** 79.8% SWE-bench Multilingual—0.7 points behind Opus 4.7—at $0.50/M input tokens.

Composer 2.5 is built on Moonshot's Kimi K2.5 open-source checkpoint and trained with 25× more synthetic tasks than its predecessor, with targeted textual feedback injected at the exact trajectory points where the model underperformed. Cursor credits those targeted RL improvements for closing most of the gap to frontier-class models without a clean-sheet pretraining run.

More consequentially, Cursor disclosed that its next model will be trained from scratch on SpaceXAI's Colossus 2 supercluster—equivalent to roughly one million H100 GPUs—using 10× more total compute than Composer 2.5. That infrastructure access comes from the April 21 agreement that gives SpaceX the right to acquire Anysphere (Cursor's parent) for $60 billion later this year.

## 2️⃣ xAI Enters the Coding Agent Race with Grok Build

- **What:** xAI launched Grok Build on May 15—an agentic CLI powered by Grok 4.3 beta, with a 2M-token context window and support for up to 8 concurrent agents.
- **Why it matters:** Elon Musk previously admitted xAI had fallen behind on coding AI; Grok Build is the company's direct answer to Claude Code, with the largest context window of any coding CLI at public release and a "plan mode" requiring user approval before executing changes.
- **Key number:** 2 million token context window—broadest of any coding agent CLI at launch.

Grok Build uses the Grok 4.3 Heavy architecture featuring 16 sub-agents that can simultaneously plan, search documentation, and write code. Like other coding CLIs, it can plan projects, write and edit files, run shell commands, and build complete applications from natural language prompts. Plan mode—where the model proposes a structured task breakdown and waits for user sign-off before touching the codebase—is a notable safety differentiator. Access is currently restricted to SuperGrok Heavy subscribers ($300/month), with broader availability unannounced.

## 3️⃣ OpenHuman: 11,600 GitHub Stars in 15 Days by Front-Loading Your Context

- **What:** OpenHuman (tinyhumansai/openhuman), an open-source desktop AI agent, hit #1 on GitHub Trending and Product Hunt by syncing 118+ connected apps—Gmail, Notion, GitHub, Slack, Stripe, Linear, Jira—into a local SQLite knowledge base before you type a single prompt.
- **Why it matters:** Competing agents start each session cold or rely on cloud memory; OpenHuman's Memory Tree compresses your entire connected context into ≤3k-token Markdown chunks stored locally, delivering personalized responses on day one without routing data through third-party servers.
- **Key number:** 11,600 GitHub stars in 15 days; #1 on both GitHub Trending and Product Hunt weekly.

OpenHuman is structured around three primitives: a one-click OAuth sync layer (covering most common work tools), a Memory Tree that canonicalizes everything into local SQLite, and an Obsidian-compatible wiki built from your activity over time. The v0.53.43 release on May 13 marked the public debut; v0.54.0 followed with expanded integration support. The project is MIT-licensed and runs locally on Mac and Linux, connecting to whichever LLM the user supplies via API key.
