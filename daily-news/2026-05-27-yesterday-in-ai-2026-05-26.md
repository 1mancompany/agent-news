## 1️⃣ Anthropic's Mythos Surfaces 23K Security Flaws in 1,000 OSS Projects — and Is Coming to Claude Code

- **What:** Anthropic published Project Glasswing's first numbers: Claude Mythos Preview scanned 1,000+ open-source projects and flagged 23,019 potential vulnerabilities, with 6,202 estimated high or critical severity. One confirmed find — a cert-forging bug in wolfSSL (CVE-2026-5194) — came with a working exploit built by Mythos.
- **Why it matters:** Mythos is being integrated into Claude Code and Claude Security, which means AI-driven vulnerability scanning is on its way into developers' daily workflow as a default, not an optional audit.
- **Key number:** Only 97 of the flagged vulnerabilities have been publicly patched; open-source maintainers told Anthropic to slow down its disclosure rate.

Anthropic's 50-partner Project Glasswing coalition spans major tech firms, government security agencies, and independent pen-test firms. Mozilla audited Firefox with Mythos and fixed 271 vulnerabilities. Cloudflare scanned its critical-path systems and found ~2,000 bugs (400 high/critical) at a false-positive rate lower than that of human testers.

Mythos briefly appeared as a selectable toggle inside Claude Code on May 25 before being pulled — a signal that a limited release is actively being tested. Anthropic says it still lacks sufficient misuse safeguards for a public launch, but the model is now filing its own CVE records and is on track to surface an estimated 3,900 confirmed high/critical flaws in open-source code.

## 2️⃣ xAI Launches Grok Build: CLI Coding Agent With 2M-Token Context, Arena Mode, and 8 Parallel Subagents

- **What:** xAI launched Grok Build in early beta on May 25 — a terminal-first coding agent with a 2M-token context window, plan-and-approve mode, and parallel subagents. It enters a market currently led by Claude Code and OpenAI Codex.
- **Why it matters:** Arena Mode, which runs multiple AI models side-by-side on the same coding task so developers can compare outputs before committing, is a differentiation no major competitor currently ships.
- **Key number:** 8 concurrent subagents can work on separate branches in parallel.

Grok Build installs with a single shell command on macOS/Linux or a PowerShell one-liner on Windows. The underlying model — Grok Build 0.1 — was available via xAI's API on May 20, five days before the CLI beta shipped. The 2M-token context window is the largest among CLI coding agents and allows loading entire medium-sized repositories in a single turn.

The tool is gated to SuperGrok ($299/month) and X Premium Plus subscribers during beta. Grok Build 0.1 is already listed as an OAuth provider in the Hermes Agent framework, suggesting fast third-party adoption.

## 3️⃣ Cerebras Runs Open-Weight Kimi K2.6 at 981 Tokens/Sec — 6.7× Faster Than Any GPU Cloud

- **What:** Post-IPO Cerebras announced enterprise trials serving Moonshot AI's Kimi K2.6 — currently the top open-weight coding model on SWE-Bench Pro — at 981 output tokens per second, independently verified by Artificial Analysis.
- **Why it matters:** The gap between Cerebras and the next-fastest GPU cloud is so wide (6.7×) that it effectively makes real-time coding-agent loops with a trillion-parameter model feasible for the first time.
- **Key number:** 5.6 seconds vs. 163.7 seconds for a 10,000-token request — a 29× end-to-end speedup.

Kimi K2.6 tops SWE-Bench Pro at 58.6%, outperforming Claude Opus 4.6 and matching GPT-5.4 on agentic coding benchmarks. It has 1T total parameters, 32B active per token, a 1M-token context window, and is available under a Modified MIT license. Cerebras is the only provider currently serving it below 10 seconds end-to-end for long-context requests.

Cerebras went public on May 14, raising $5.55B at $185/share (stock opened at $385 on Nasdaq: CBRS) in the largest US tech IPO since Uber's 2019 debut. This K2.6 enterprise-trial announcement is the company's first major post-IPO technical benchmark — and a direct challenge to Nvidia's dominance over AI inference at scale.
