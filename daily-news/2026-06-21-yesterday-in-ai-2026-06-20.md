## 1️⃣ Matt Pocock's Claude Code Skills Framework Crosses 139K Stars

- **What:** TypeScript educator Matt Pocock released v1.0.1 of `mattpocock/skills`, a collection of 21 composable Claude Code skills addressing the top failure modes in AI-assisted engineering: agent misalignment, excessive verbosity, and architectural decay.
- **Why it matters:** Unlike BMAD or Spec-Kit which own the entire process, these skills are a lightweight contract layer — developers stay in control while eliminating the most common Claude Code complaint: technically correct output that misses the actual goal.
- **Key number:** 139K stars and 12K forks; v1.0.1 cuts skill-load token costs 63% through progressive disclosure.

The framework ships as 21 plain markdown files. `/grill-with-docs` front-loads alignment by making Claude ask detailed questions before writing code, then saves shared vocabulary to `CONTEXT.md`. `/tdd` enforces a test-first loop on every change. `/caveman` strips agent verbosity to near-zero when the path is already clear.

Version 1.0.1, released June 17, added a formal user-invoked vs. model-invoked taxonomy — a subtle but important distinction that prevents Claude from running skills unsolicited — along with design workflows and shared session state. Pocock has a 60,000-subscriber developer newsletter, which explains why 1,395 stars landed in a single day on June 20. The repo overtook several established AI frameworks by star count within its first month.

## 2️⃣ Netflix Engineer's `headroom` Hits #1 GitHub Trending With 95% Token Cuts

- **What:** Tejas Chopra, Senior Engineer at Netflix, open-sourced `headroom`, a context compression layer that intercepts tool outputs, logs, RAG chunks, and conversation history before they reach the LLM — deployable as a Python library, transparent proxy, or MCP server.
- **Why it matters:** Enterprise AI budgets are hitting walls — Uber capped coding tool spend at $1,500/month — and headroom directly attacks the root cause by compressing what agents send, not what they do.
- **Key number:** 60–95% token reduction with no quality loss on GSM8K, TruthfulQA, and SQuAD v2; 3,795 stars gained on June 20 alone.

Six compression algorithms handle different payloads: SmartCrusher targets JSON, CodeCompressor works on AST-parsed code, and Kompress-base is a learned text model. In proxy mode, zero agent code changes are required. A `headroom learn` command mines failed sessions to write domain-specific correction rules automatically.

Real workload numbers are stark: code search drops from 17,700 tokens to 1,400 (92% cut); SRE incident debugging falls from 65,694 tokens to 5,118. Original content is cached locally for retrieval on demand, making compression fully reversible. Cross-agent memory syncs context across Claude, Codex, and Gemini with automatic deduplication. At 42K stars and currently the #2 monthly trending project, headroom is the breakout AI infra release of June.

## 3️⃣ `codebase-memory-mcp` Brings 158-Language Knowledge Graph to MCP Agents

- **What:** DeusData released `codebase-memory-mcp`, a zero-dependency single binary MCP server that indexes any codebase into a persistent knowledge graph using tree-sitter parsers, then exposes 14 MCP tools for code search, call tracing, change detection, dead code analysis, and cross-service HTTP link detection.
- **Why it matters:** AI coding agents currently waste enormous context reading files one by one; a persistent queryable graph lets agents ask "what calls this function?" without loading entire directories — and answers persist across sessions.
- **Key number:** 99.2% token reduction versus file-by-file exploration; Linux kernel (28M lines, 75K files) indexed in 3 minutes.

The server auto-configures for 11 coding agents including Claude Code, GitHub Copilot, and Cursor. Hybrid LSP integration adds semantic type resolution for Python, TypeScript, Go, Rust, Java, and C++ — so it understands type context, not just symbol location. An optional 3D graph visualization UI ships bundled.

v0.8.1 landed June 12 with cross-service HTTP linking and dead code detection. The server adds 1,271 stars on June 20 against a 9.6K base, with acceleration driven by agent developers hitting context window limits on large monorepos. For teams running Claude Code's dynamic workflows over multi-service architectures, this fills a real gap.
