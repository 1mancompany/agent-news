## 1️⃣ OpenAI DevDay 2026: 800M Weekly Users and Managed Agents Debut

- **What:** OpenAI held DevDay 2026 in San Francisco (Sept 29), unveiling Managed Agents, an Apps SDK with partners Booking.com and Spotify, and a 20× API throughput increase.
- **Why it matters:** Managed Agents replaces the deprecated Agent Builder — it lets developers deploy fully hosted AI agents with customizable environments, skills, and plugins in one click, killing the infrastructure setup step.
- **Key number:** 800 million weekly active users — up from 500M that ChatGPT reported in early 2025.

OpenAI's annual developer conference was packed. ChatGPT reached 800M weekly active users, a milestone Sam Altman credited to enterprise adoption and international growth. The developer count doubled to 4 million, and API token throughput reached 6B tokens per minute — a 20× jump year-over-year.

The centrepiece announcement was Managed Agents, which replaces the now-shut-down Agent Builder (deprecated June 3, dead November 30). Where Agent Builder required infrastructure setup, Managed Agents is serverless: define skills, attach tools, set a budget, and deploy. OpenAI also launched the Apps SDK, letting developers embed interactive mini-apps inside ChatGPT conversations — launch partners include Booking.com, Spotify, Canva, and Zillow.

## 2️⃣ Anthropic Opens Claude to All Three Branches of the U.S. Federal Government

- **What:** Anthropic made Claude for Government generally available on September 30, expanding beyond pilots to all three branches of the U.S. federal government via GSA procurement.
- **Why it matters:** Federal agencies now have a direct, FedRAMP-aligned path to Claude for sensitive-but-unclassified workloads — with multicloud support and hands-on technical assistance that OpenAI's government track doesn't match.
- **Key number:** 3 — all three branches of the U.S. federal government now have access.

Claude for Government moves into a purpose-hardened deployment track. Anthropic is working with the General Services Administration to slot it into existing federal procurement pathways, removing the long lead times typical of custom software contracts. The offer includes multicloud deployment options and hands-on technical assistance at no extra tier cost.

In parallel, Claude Code received new enterprise controls on September 30 — MCP policy settings, portable desktop config files, faster session resume, and new agentic permission controls — continuing a steady series of hardening updates targeting government and regulated-industry deployments.

## 3️⃣ codebase-memory-mcp: A Zero-Dependency Server Giving Agents Permanent Code Memory

- **What:** DeusData/codebase-memory-mcp hit 9,400 GitHub stars and topped MCP trending charts, offering a persistent codebase knowledge graph that agents can query in under a millisecond.
- **Why it matters:** AI coding agents lose all repo context when sessions reset; this server preserves the full codebase graph in a single static binary with no dependencies, surviving restarts and context compaction.
- **Key number:** 99% — claimed token reduction versus passing raw code into an LLM context window.

The codebase-memory-mcp is written in C for speed and indexes any of 158 supported languages into a graph queried via MCP tool calls. No vector database to deploy, no re-indexing on restart, no dependencies. Each query returns symbol relationships, file locations, and call chains in sub-millisecond time, and the index survives Claude Code session resets.

For teams running parallel Claude Code workers — including those using the Claude Code Projects multi-thread beta — the server solves a real bottleneck: worker threads previously had to re-read the entire codebase from scratch on each spawn. With a shared MCP memory layer, workers can pick up mid-task without context loss. The project is currently #2 on GitHub's MCP trending list with 710 forks.
